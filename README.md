# GROW BOOK

장편 글쓰기, 페이지형 독서, 커뮤니티 반응과 출판 후보 검증을 위한 풀스택 테스트 프로젝트입니다. 배포 환경뿐 아니라 Visual Studio Code의 로컬 환경에서도 실행할 수 있습니다.

## 준비 사항

- Node.js 22.13 이상
- npm 10 이상
- Visual Studio Code

## Visual Studio Code에서 실행

1. 압축을 풀고 해당 폴더를 Visual Studio Code로 엽니다.
2. VS Code 상단 메뉴에서 `터미널 → 새 터미널`을 엽니다.
3. 아래 명령을 순서대로 실행합니다.

```bash
npm install
npm run dev:local
```

4. 터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 일반적으로 `http://localhost:5173`입니다.

`npm run dev:local`은 최초 실행 시 로컬 Cloudflare D1 데이터베이스를 만들고 `drizzle/`의 마이그레이션을 모두 적용한 뒤 개발 서버를 시작합니다. 작성한 테스트 데이터는 프로젝트 내부의 `.wrangler/`에 보관됩니다.

Windows PowerShell, macOS, Linux에서 같은 명령을 사용할 수 있습니다. 로컬 준비 명령은 운영체제와 관계없이 Node.js로 실행되며 별도의 Bash 설치가 필요하지 않습니다.

두 번째 실행부터 데이터베이스 준비가 필요 없다면 다음 명령만 사용해도 됩니다.

```bash
npm run dev
```

## 검사와 프로덕션 빌드

```bash
npm run lint
npm run build
npm test
```

위 명령도 Windows PowerShell, macOS, Linux에서 동일하게 실행됩니다. 배포 서버 전용 검사가 필요한 경우에만 `npm run build:sites`를 사용합니다.

## 테스트 계정 사용

로그인하지 않아도 공용 `테스트 작가`로 모든 핵심 흐름을 확인할 수 있습니다. 회원별 데이터 분리를 함께 시험하려면 `/login`에서 로컬 계정을 만든 뒤 사용하세요. 로컬 계정과 세션은 외부 서비스로 전송되지 않고 로컬 D1 데이터베이스에만 저장됩니다.

### 로컬 관리자 로그인

로컬 실행 후 `/admin`에서 아래 테스트 관리자 계정으로 로그인할 수 있습니다.

```text
아이디: growbook-admin
비밀번호: GrowBook-local-2026!
```

로그인하기 전에는 관리자 데이터와 관리 기능이 전혀 렌더링되지 않으며, 관리자 API도 `401`로 차단됩니다. 위 계정은 로컬 테스트 전용입니다. 공개 배포는 소스와 분리된 환경 변수의 별도 계정을 사용합니다.

`npm run dev:local`은 `.dev.vars.example`을 바탕으로 로컬 전용 `.dev.vars`를 자동 생성합니다. 로컬 관리자 비밀번호를 바꾸려면 `.dev.vars`만 수정하면 되며, 이 파일은 버전 관리와 배포에서 제외됩니다.

## 로컬 데이터 안내

- 로컬 테스트 데이터: `.wrangler/`
- 로컬 도구 설정: `.local-runtime/`
- 공개 사이트 데이터와 로컬 데이터는 서로 동기화되지 않습니다.
- ZIP에는 테스트 중 생성한 데이터와 의존성 폴더가 포함되지 않습니다.
- 새로운 테스트 환경이 필요하면 프로젝트를 새 폴더에 압축 해제하고 `npm install`, `npm run dev:local`을 다시 실행하면 됩니다.

## 테스트 모드 주의사항

현재는 로그인하지 않은 방문자가 공용 `테스트 작가` 데이터를 함께 사용할 수 있습니다. 관리자 권한은 별도 쿠키 세션과 환경 변수 계정으로 분리되어 있습니다. 실제 서비스 전환 시에는 이메일 인증·비밀번호 재설정, 개인정보·약관 문서의 법률 검토, 외부 메일·알림 발송, 정기 원격 백업과 결제대행사 연동이 추가로 필요합니다. 후원·판매·정산 금액은 기능 검증용 테스트 기록이며 실제 결제되지 않습니다.

예약 발행은 일반 접속 시에도 처리되며, 정식 운영에서는 `POST /api/cron/publish`를 정기 작업에 연결할 수 있습니다. 요청에는 32자 이상의 `SCHEDULED_JOB_SECRET`을 Bearer 토큰으로 보내야 합니다.

## 데이터 구조 변경

`db/schema.ts`를 변경한 경우 다음 명령으로 마이그레이션을 생성하고 로컬 데이터베이스에 적용합니다.

```bash
npm run db:generate
npm run dev:setup
```
